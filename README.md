# Research Repository

## Purpose
This repository is dedicated to the **Fact-Finding** and **Research** phase of the SENG 31242 System Design Project. It contains all evidence gathered during the problem exploration and analysis stages.

## Directory Structure
- `literature-review/`: Notes and summaries from secondary research and existing literature.
- `competitive-analysis/`: Comparison matrices and evaluation of existing solutions.
- `interviews/`: Transcripts, summaries, and key findings from stakeholder interviews.

## Tooling
- Markdown for documentation.
- Spreadsheet tools (CSV/Excel) for comparison matrices.
- Audio/Video players for interview recordings (if applicable).

## Standards
All documents in this repository must follow the project's commit and branching conventions outlined in `CONTRIBUTING.md`.
